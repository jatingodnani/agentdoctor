# AgentDoctor

A crash-test lab for AI agents. This package provides tools and utilities for testing and evaluating AI agent performance across multiple LLM providers.

## Installation

```bash
npm install agentdoctor
```

## Features

- Support for multiple AI providers:
  - Anthropic
  - OpenAI
  - Amazon Bedrock
  - OpenAI-compatible services
- Type-safe agent development with TypeScript
- Comprehensive testing utilities

## Usage

```typescript
import { /* your exports */ } from 'agentdoctor';
```

## Development

```bash
npm install
npm run try
```
